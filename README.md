# ProyectoPoo
repositorio para subir el programa del proyecto

## Instalación

Instala las dependencias con:

```bash
python -m pip install -r requirements.txt
```

La interfaz permite cargar archivos CSV mediante el botón **Cargar CSV** o
arrastrándolos a la zona indicada. Los archivos se copian a `datos_experimento`
y sus datos se muestran en la tabla y la gráfica.
