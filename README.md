# ProyectoPoo
repositorio para subir el programa del proyecto

## Instalación

Instala las dependencias con:

```bash
python -m pip install -r requirements.txt
```

La interfaz permite cargar archivos CSV mediante el botón **Cargar** o
arrastrándolos a la zona situada junto a **Actualizar lista**. Los archivos
seleccionados se procesan y sus datos se muestran en la tabla y la gráfica.
